# Snooker v1.1.0 — 俱乐部首页与逐局结算

v1.1.0 为本地斯诺克对战加入暂停和逐局回顾流程：可随时暂停比赛，查看台面理论剩余分数，并在每局结束后回顾双方比分、单杆最高分和进球顺序。首页采用英伦俱乐部风格，保留人机对战与同机双人模式。

以下为相较 v1.0.0 的变更。

## 新增与改进

### 英伦俱乐部首页

- 墨绿、铜色与暖白配色，搭配透视球台、球杆和模式选择卡片。
- 左下角版本号自动读取项目版本；右下角显示 `Copyright 2026 Severus Chu`。
- 离线版完整许可与第三方声明移至首页右上角「版权与许可」。
- 首页、暂停菜单和结算面板适配窄屏布局。

### 暂停与继续

- 点击右上角「暂停」或按 Esc 打开暂停菜单。
- 暂停期间冻结球的运动、相机更新和 AI 思考计时；继续后从原状态恢复。
- 暂停菜单提供「继续比赛」与「退出比赛」。退出返回首页，不保留本场进度。
- 暂停、恢复和退出时清理残留输入，避免误出杆或持续拖动。

### 台面剩余最高分

- 比分板的 `Reds` 替换为 `Points Remained`。
- 按当前球局计算理论可得最高分，包括每颗红球后的彩球、最后一颗红球后的待打彩球、清彩分数和已经获得的自由球机会。
- 常规开局显示 147；最后红球打进、尚待打彩球时显示 34；进入完整清彩阶段显示 27。
- 不预估未来犯规产生的罚分。

### 每局结算与击球记录

- 每个 Frame 结束后展示本局比分、双方单杆最高分及比赛大比分。
- 按每次上台的先后顺序展示进球序列和单杆得分。例如两套红黑显示为「红球、黑球、红球、黑球」，该次单杆为 16 分。
- 犯规用中央带罚分数字的白球表示；罚分计入对手总分，不计入单杆最高分。
- 交换击球权用带 ↻ 符号的白球表示；记录保留要求犯规方继续与复位重打的交接。
- 自由球保留实际球色并作标记，按规则给出的实际分数计入单杆。
- 结算数据保留至用户确认，点击「下一局」才重新摆球；比赛结束后可「再来一场」或返回首页。

### 自定义赛制

- 支持自行输入比赛总局数，只接受正奇数。
- 偶数、零、负数、小数或空值会禁用开始按钮并提示修改。
- 获胜局数为（总局数 + 1）/ 2，例如 9 局 5 胜、35 局 18 胜；支持提前获胜与决胜局。

## 规则修复

- 贴目标球合法打离不再误判未碰球；贴球本身不得分。
- 分别处理指定彩球、重新指定彩球及自由球的贴球条件。
- 根据初始贴合阶段的碰撞冲量识别推杆；合法打离后碰库返回不会被误判为初始推杆。
- 推杆犯规正确罚分，保留此前各杆得分，并允许要求犯规方从现有球位继续。
- 犯规结束本局时，结算面板保存本杆罚分；复位重打保留已判罚分及记录。

## 下载与运行

- `Snooker-v1.1.0.html`：完整离线单文件游戏，保存到本机后用支持 WebGL 2 的 Chrome / Edge 等桌面浏览器打开。
- `Snooker-v1.1.0.zip`：包含上述 HTML、游玩说明、发布说明、项目许可及第三方声明。
- `SHA256SUMS.txt`：HTML 与 ZIP 的 SHA-256 校验值。
- 无需安装 Node.js、npm、Python，无需启动服务器或联网。聊天软件的文件预览不能代替浏览器运行。

## 验证

- 80 项自动化回归测试通过，覆盖物理、规则、自定义赛制、剩余分数、进球记录、单杆统计与结算推进。
- TypeScript 检查、常规构建与离线构建通过。
- 浏览器验证包括模式切换、局数校验、暂停/继续/退出、运动中暂停画面冻结，以及桌面和窄屏结算布局。

## 当前边界

本项目仍为可玩的物理 demo，尚未经过实台数据标定；部分裁判规则、极端杆法和架杆几何为近似。AI 为实验实现，当前重点为本地双人模式。

无联网对战或存档功能。退出比赛、关闭或刷新页面会丢失当前进度。
