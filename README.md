## 本地开发

```powershell
npm ci
npm run dev -- --host 127.0.0.1
```

## 制作离线发行版

```powershell
npm run build:standalone
```

在 `release/` 生成 HTML、ZIP、操作说明、版权文件和 `SHA256SUMS.txt`。
构建将 TypeScript 和 Three.js 打包为内联经典脚本，省去本地文件下的模块加载与跨域依赖。

## 键鼠操作

- 右上角「暂停」或 Esc 暂停比赛，冻结球、相机与 AI 思考计时；可继续或退出返回首页（退出不保存本场进度）。
- 比分板的 `Points Remained` 显示当前球局理论可得最高分，包括每颗红球后的彩球、最后红球后的待打彩球与已经获得的自由球机会，不预估未来犯规送分。
- 每个 Frame 结束后显示本局分数、双方单杆最高分和按上台顺序排列的记录。彩球图案表示得分顺序，白球中的数字表示罚分给对手，白球中的 ↻ 表示交换击球权；罚分不计入单杆最高分。点击「下一局」后才重新摆球，比赛获胜后可再来一场或返回首页。

- 开始菜单可自定义总局数，只接受正奇数；输入 9 即为 9 局 5 胜，输入 35 即为 35 局 18 胜。率先赢得（总局数 + 1）/ 2 局的一方获胜，比赛中显示当前赛制。
- 开局点击 D 区放置白球。
- 按住左键拖动瞄准，单像素移动也生效。松开鼠标不会出杆。
- **空格或“出杆”按钮击球**；被库沿、球或支架挡住时会禁用出杆并提示原因。
- **F** 切换精瞄；按住任意 **Shift** 临时精瞄。
- 左右方向键短按：普通每次 0.02°，精瞄每次 0.002°；按住 0.25 秒后连续调整。底部左右微调按钮每次 ±0.005°。
- 左侧竖条显示和调节力度，右侧竖条显示和调节倾角，不显示具体数值。滚轮、上下方向键仍调力度；精瞄时力度也更细。拖完滑条可直接按空格出杆。
- 右下角球面选择高低杆、左右塞，双击恢复中杆；每杆结束后自动回到中央。击球点限制在半径的 50% 范围。
- 每杆默认自动使用最低可用倾角，随瞄准方向、击球点、库边、球堆及支撑类型变化。拖动右侧条后保持手动倾角，点击条下方按钮恢复自动；无可用角度时保持禁止出杆。内部角度搜索范围 0–80°，步长 0.5°。
- 支撑可选手架、十字架杆、高架杆（Spider）；支撑高度与落脚处的球会限制杆路。
- 打入红球后选择本杆彩球，出杆前可通过“更换彩球”重新指定，保留力度与杆法；获得自由球时选择代替球或放弃。当前目标、精瞄、支撑与出杆入口位于底部，两侧控制条仅在本地玩家瞄准时显示。

## 物理与画面

球体使用三维位置/速度与三轴角速度。球杆姿态、实际击球点和冲量共同决定平移与旋转。抬杆向下击球，碰撞台呢/石板后可以离台；重力控制腾空与落地，空中不施加台呢摩擦。扎杆曲线来自倾斜出杆产生的旋转与落地摩擦，不是预设弯线。

固定 240 Hz 步进，连续求解球球、库鼻、袋角接触。碰撞使用法向恢复冲量和受库仑摩擦限制的切向冲量。滑动到滚动在接触点滑移归零时切换，多球接触采用事件迭代和重叠修正。

球杆显示与限制共用三维姿态，检查渐粗杆身与其他球、库沿的间隙。手架落点和架杆落脚也受球堆限制。库鼻高度、库顶高度独立设置；六段胶边使用连续圆弧近似，渲染与碰撞共用轮廓。石板在角袋处实际开口，袋口有石板边缘、后侧皮口和向下的袋腔。球心越过袋沿后锁定入袋状态，平滑收向袋腔并持续下沉，在台面下 75 mm 计入进袋。已移除袋内皮口和石板边缘的反弹；袋口外的圆角胶边仍会正常拒球。落在木库或飞出台面单独判离台。粉球点修正为台面长度的 3/4，首颗红球紧邻粉球但不相贴。

辅助线复制球局并使用同一引擎；最多预测 4 秒，首次球/库碰撞后显示约 0.9 秒。参数改变时最多每 80 ms 重算。

## 贴球与推杆判定

依据文件夹中官方手册及 WPBSA 当前官方规则第 3 节第 8 条、第 11(b)(v) 条，兼顾第 2 节第 19/20 条。

- 贴住目标球（或最终指定的彩球 / 自由球）后，合法打离即满足首次碰球要求；贴球本身不得分。
- 只贴住非目标球，或改选另一颗彩球，仍须先碰到本杆指定目标球。
- 出杆时推动贴球判推杆，罚分至少 4 分，取目标球与涉及球分值的较高值。本杆进袋不得分，已结束各杆的得分保留。
- 初始贴合阶段记录冲量，多颗贴球分别检查；合法打离后的碰库返回、碰撞传递不按初始推杆误罚。
- 球心接触容差为 0.01 mm；0.1 mm 可见间隙不算贴球。非碰撞导致的微小位置修正不算推杆。
- 犯规后可自己接手，或让犯规方从现有球位继续；合法打离不判 Miss，推杆本身不提供无条件复位重打。

## 判罚与对战流程

- 自由球检查任一目标球的**两个极边**是否都能直接到达；同属 ball-on 的球不作为遮挡球，库边也不构成规则意义的斯诺克。
- 犯规后先复位彩球、计算接手玩家的目标球，再判自由球。白球在手时搜索整个 D 区合法落点，不能通过选择被挡位置获得自由球。
- 自由球不可指定实际目标球，按目标分值计分并复位；同时进红球分别计分，同时进自由彩球和实际目标彩球只计一次。检查使用指定自由球造成斯诺克及末两球例外。
- 根据越球、首次接触、碰库和落地事件判跳球，处理先碰球后越过另一球、击球后落在近侧、经库/其他球后越过原球等例外；仅腾空不直接判犯规。
- 清彩阶段犯规导致进袋/离台的彩球复位。重打恢复击球前球局、击球者与目标阶段，保留罚分。
- 超分仍可继续做斯诺克；末黑得分或犯规结束本局，同分则复位黑球、自动抽签决定击球方、进入 D 区放置。
- 修复连续弹窗互相隐藏，避免自由球/彩球选择卡住；局间重新摆球。

规则依据：[WPBSA 2024–25 手册](https://wpbsa.com/wp-content/uploads/2198_WPBSA-Rulebook-2024-25.pdf)的球台点位、Snookered、Jump Shot、Snookered After a Foul、末黑条款。
